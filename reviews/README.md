# Original AI review outputs

[ChatGPT](chatgpt/), [Gemini](gemini/) and [Claude](claude/) each contain 21 original text files, keyed by submission ID in `paper_id_N.txt`. All text is preserved, including scores, links, formatting and assistant follow-up offers.

Use the [paper catalogue](../papers/README.md), [common prompt](../protocol/review-prompt.txt) and [extracted scores](../data/review-scores.csv) to navigate and analyse the reports.

**Gemini paper 23 duplicates paper 22 and describes paper 22.** It is retained as evidence of the assignment issue. There are 63 files and 62 distinct byte sequences. See [known issues](../docs/known-issues.md).

Product-folder labels do not establish exact model versions or run settings. Review assertions are AI output, not independently verified facts.
